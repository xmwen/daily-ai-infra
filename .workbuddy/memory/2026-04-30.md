## 今日 AI Infra 关键信号

### 推理侧（arXiv 集中爆发）
- **RaMP**：MoE 推理路由感知 kernel dispatch，4 参数 wave 代价模型从 CTA grid 几何推导，在 8 架构（含 3 个未见）上平均遗憾 0.93% vs exhaustive search，每模型 10-24min 一次性 profiling。与用户研究的 DeepGEMM Mega MoE kernel dispatch bubble 问题直接相关。
- **DUAL-BLADE**：NVMe KV cache offload 双路径——page-cache 路径 vs NVMe-direct LBA 路径，按运行时内存压力动态切换；direct 路径绕开文件系统避免 page cache thrashing。补齐长上下文 KV 溢出 storage stack。
- **DAK**：用 TMA 异步直接访问远端 tier memory，不 prefetch 到本地 HBM，避开 HBM 争用和 pipeline bubble；把 direct-access 做成系统原语。
- **FACT**：agent 驱动 kernel 合成 grounded 到 CUTLASS C++ 而非裸 CUDA，LLM agent 不重新发明库已有优化，只在 catalog 缺失处补洞。对 agent-based kernel 生成方向的工程边界定义。
- **AMMA**：multi-chiplet memory-centric 架构服务 1M 上下文 attention，KV cache 下沉 PIM/PNM chiplet 就近计算，GPU 只做剩余部分。针对长上下文 + agentic workload 下 attention 是 memory-bound 与 GPU 架构错配的本质问题。
- **SPIN**：稀疏 attention 与分层 KV 存储统一框架，算法级稀疏收益真正落到端到端。
- **AHASD**：移动端 NPU+PIM 投机解码，task-level DLM-TLM 解耦，drafting 在 PIM verification 在 NPU。
- **长程投机解码新角度**：target hidden state 是按当前 attention query 做的有偏上下文压缩，擅长下一 token 但压缩远程信息，用 KV cache 反向恢复远程上下文。对 KV cache 量化 + 投机解码精度链路有借鉴。
- **逆向 NVIDIA 闭源 userspace driver 命令流**：利用开源 kernel driver 打桩 memory-mapping 路径 + GPU doorbell 寄存器硬件断点，完整捕获 CUDA API→硬件命令的翻译链路。对国产芯片做 CUDA 语义对齐、对 kernel 级性能建模（用户 VisitorBound_Scorpiox2 方向）都是难得的白盒材料。

### 训练侧
- **TSP**（Folding Tensor and Sequence Parallelism）：把 TP 与 SP 折叠到同一 device 轴，每个 rank 同时持有 weight shard 和 sequence shard，同一轴同时降参数与激活内存。是 3D 并行之外的新轴折叠范式。
- **COPUS**：batch size 与 3D 并行策略本质耦合，需联合自适应而非各自独立调整。
- **DORA**：RL post-training 异步训练，针对长尾轨迹阻塞，识别保持收敛的三个约束——轨迹内策略一致性/数据完整性/有界 staleness。
- **KTransformers v0.6.1**：大 MoE LoRA SFT 重构到 kt-kernel，相对 ZeRO-Offload 训练性能 6-12×，CPU 内存降一半。
- NeMo-RL + vLLM 投机解码 RL rollout：把 spec decoding 作为无损加速原语用到 RL 训练 rollout，打通推理-训练联动。
