## 技术讨论：SmoothQuant vs AWQ 区别

用户问两者方法"非常类似"时该如何区分。核心差异已澄清：

- **SmoothQuant（W8A8）**：痛点是激活 outlier 打爆 per-tensor INT8 scale。用 $s_j = \max(|X_j|)^\alpha / \max(|W_j|)^{1-\alpha}$（α=0.5）把难度**从激活搬到权重**，两侧都量化。硬件收益来自 INT8 GEMM 算力 2×，适合 prefill / 高吞吐 batch。
- **AWQ（W4A16）**：只量化权重。关键 insight 是 salient weight channel 的判定**看激活幅值而非权重自身**（activation-aware），对 top ~1% salient 通道做 per-channel scale 放大，grid search α 最小化量化 MSE。硬件收益来自 decode memory-bound 下 weight 带宽 4×，但**必须有 fused INT4 dequant-GEMM kernel** 否则白搞。

两者公式都是 $Y = (X/s)(sW)$ 的等价变换，但：
- SmoothQuant 是"均衡两侧难度"（α=0.5 钦定）
- AWQ 是"只对 salient 通道激进放大"（α grid search，非 salient 通道 s≈1）
- 方向相反：SmoothQuant 救激活，AWQ 救权重

## 工程关联（Ascend/TOPS）
- prefill 优化走 SmoothQuant 路线，复用现成 INT8 GEMM
- decode 优化走 AWQ 路线，tops::dot 层面要做 W4A16 fused dequant→matmul（两步做会失去带宽收益）
- vLLM/SGLang 现在是 prefill/decode 分开调度不同 kernel 的主流做法

## AWQ salient channel 的准确定义（追问澄清）

**salient weight channel = 对应激活幅值大的那个权重输入通道**，不是权重自己大的通道。

论文实测三种选法（INT4 Wikitext PPL）：
- (a) 一视同仁：PPL 爆炸
- (b) 按 ‖W_j‖ 选：几乎无效 ❌（常见误读）
- (c) 按 ‖X_j‖ 选：大幅恢复 ✅

理论依据：ΔY = X·ΔW，第 j 通道对输出误差的贡献是 |X_j|·|ΔW_j|。|ΔW_j| 跨通道差异小（由量化 step 决定），|X_j| 跨通道差异大（LLM 激活 outlier 集中在少数 channel）。所以决定保护谁的是激活，不是权重。

**Top 1% 说法澄清**：那是论文 Figure 2 motivation 实验（混合精度假设保留 top 1% 为 FP16），证明关键通道稀疏。但最终方法是**连续 per-channel scaling** $s_j = a_j^\alpha$（a_j 为该通道激活 mean-abs），α 在 [0,1] grid search 最小化层级 MSE，典型 α=0.5~0.9，**不存在离散 top-1% 阈值**。

**为什么放大能保护**：per-group 量化下 Δ 由 group max 决定，只放大少数 salient 通道不会拉爆 Δ，被放大的通道在固定 Δ 下相对误差被压低；非 salient 通道误差略增但激活小，|X_j·ΔW_j| 仍小。整层 MSE 下降。

**放大的条件与上限（追问澄清）**：放大能提精度有前提 —— s·|w_salient| 不能顶穿 group max，否则 Δ 被拉爆反而整组亏。本质是**在固定 Δ 预算下做精度重分配**，从非 salient 通道抠出位宽投喂给 salient 通道。不是免费午餐，有上限。这也是必须 grid search α 的原因：在"放大降 salient 相对误差"和"Δ 被推高整组亏"之间找平衡。与 SmoothQuant α=0.5 钦定不同，AWQ 每层最优 α 不同（典型 0.5~0.9），因为救的约束结构不同（SmoothQuant 救 per-tensor INT8 activation scale，AWQ 救 per-group INT4 weight Δ）。

**kernel 侧关键**：grid search 和 scale 融合在**量化阶段**完成，kernel 看到的是一份已经重缩放过的普通 INT4 weight + 对应 group scale，不需要运行时区分 salient/非 salient，硬件友好。

**工程融合侧**：s 已 fuse 进量化权重；激活侧的 /s 要融进上一层（LayerNorm/前一层 Linear）输出，不能独立 op。和 SmoothQuant 的区别：SmoothQuant 的 s 也融 LayerNorm，但 AWQ 还要融 weight，**融合侧不对称**，做 kernel 集成时容易搞错。vLLM AWQ 实现是在 pack_factor 层把 scale 吃进去的。
