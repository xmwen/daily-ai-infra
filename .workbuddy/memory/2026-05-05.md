## 今日亮点
- **arXiv 推理侧再次密集爆发新 paper**：
  - **SplitZip**：PD 分离架构跨机 KV 传输专用「超快无损 KV 压缩」，GPU 原生定长编码与 RDMA 流水并行，对 disagg serving + 长上下文 + agent workload 直接补刀
  - **SANTA**：decode value-cache 从「全读+MAC」改成「post-softmax 采样+gather-and-add」无偏估计 + 分层采样方差缩减，RTX 6000 Ada decode attention vs FlashInfer/FlashDecoding 1.5×@32k
  - **StreamIndex**：DeepSeek V4 CSA 工程硬伤——公开实现要先物化 [B,S,H_I=64,T] FP32 中间张量 256GB 超 HBM；给 Triton chunked partition-merge top-k driver 永不物化
  - **PipeMax**：commodity GPU server 离线推理首次 PP+offload 联合优化，把 inactive batch KV 主动 offload，PP 通信低 + 一卡一刻一活跃 batch 是天然契合
  - **Kairos**：disagg serving 长尾感知 SLO 调度，prefill 队头阻塞 + decode straggler 对症给两套互补机制
  - **GhostServe**：流式 KV 上做 erasure coding，parity shards 放 host memory 当影子，KV 故障可恢复不重跑，给 million-token agent 长任务的容错基础设施
  - **NCCLbpf**：把 eBPF 嵌进 NCCL plugin 接口，加载时静态验证 + cross-plugin map 组合 + 原子热切换。集合通信运行时可编程性 + 安全性双补
  - **MCP Workflow Engine**：agent「思考」与「执行」解耦，一次推理产出声明式 workflow blueprint 后续直接复放，把 tool-use 工作流静态图化做缓存
  - **AAFLOW**：把 agent workflow 建模成 operator 抽象，用 Apache Arrow + Cylon 构造 zero-copy 数据平面，HPC 执行模型迁到 agent infra
  - **P3-LLM**：NPU+DRAM-PIM 集成边缘推理，混合精度量化让 PIM 吃低精度 + NPU 吃高精度
  - **GH200 多模态训练能耗跨层分析**：DeepSpeed offload/checkpointing/通信优化在统一内存超级芯片上反而可能亏能效，给国产 ScaleUp 路线建模参考
  - **LLM Serving Position Paper**：呼吁推理调度从启发式（JSQ/FIFO/LRU）转向数学最优化基础，给下一代 vLLM/SGLang 调度器定调
- **Release 侧**：
