- **根因修复 render.py（commit 2ed857e）**：原 `load_data()` 逻辑为 `curated if curated.exists() else raw`，bootstrap 时预置的静态 `cache/today_curated.json`（generated_at=09:10:00 无时区）会永久覆盖最新 fetch 结果，导致 HTML 字节级幂等、git 永远无 diff、每日 commit 不包含 HTML。修复点：
  1. `load_data()` 比较 curated 与 raw 的 `generated_at`（解析时容错无时区，视为 UTC）；当 curated 比 raw 老超过 `CURATED_STALE_HOURS=2` 小时，自动 fallback 到 raw 并打印原因。
  2. render() 新增 `Rendered: <UTC>` 徽章和 HTML `<!-- rendered_at --> / <!-- source --> / <!-- data_generated_at -->` 注释，使每次渲染产物必有唯一 fingerprint，避免未来任何幂等型 bug 掩盖 pipeline 问题。
- **经验**：脚本 pipeline 成功打印≠产物真被 commit。核对链路应用 `git log -1 --stat` + `git hash-object` 对比 HEAD blob hash，不要信 `publish.py` 的 stdout。
